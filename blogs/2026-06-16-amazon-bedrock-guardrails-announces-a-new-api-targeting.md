Amazon Bedrock Guardrails launches the InvokeGuardrailChecks API, a resourceless API providing granular, per-request control over which safeguards to run at each step of an agent loop. It returns numeric severity and confidence scores for custom thresholds and supports content filters, prompt attack detection, and sensitive information detection independently.
