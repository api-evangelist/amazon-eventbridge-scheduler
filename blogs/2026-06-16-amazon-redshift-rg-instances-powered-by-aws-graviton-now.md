Amazon Redshift expands RG instance availability to Africa (Cape Town), Asia Pacific (Bangkok), and Mexico (Central). RG instances deliver up to 4.2X better price-performance for data warehouse workloads, run 2.4x faster than RA3, and cost 30% less per vCPU, with incremental manual snapshots and zero Spectrum scanning charges.
