Web Search on AgentCore is generally available, a fully managed tool that enables agents to ground responses in current, accurate web knowledge. Built on Amazon's search infrastructure from Alexa+, Amazon Q Business, and Kiro, it combines web indexes with structured knowledge graphs and returns ranked excerpts, URLs, titles, and publication dates.
