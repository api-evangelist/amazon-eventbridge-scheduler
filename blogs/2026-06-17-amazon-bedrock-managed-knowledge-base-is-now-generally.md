Amazon Bedrock Managed Knowledge Base, a fully managed RAG service, is now generally available, handling data ingestion, storage optimization, and advanced retrieval without managing vector databases. Native connectors include S3, SharePoint, Confluence, Google Drive, OneDrive, and Web Crawler, with advanced retrieval using hybrid search, document ranking, and agentic orchestration.
