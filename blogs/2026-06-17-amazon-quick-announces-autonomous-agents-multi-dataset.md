Amazon Quick now features autonomous agents enabling users to describe tasks in natural language and set granular autonomy levels from step-by-step approval to broad goal-based execution. Multi-dataset analytics supports natural language queries across Snowflake and relational databases, and a redesigned activity feed offers conversational interfaces for prioritizing updates and approvals.
