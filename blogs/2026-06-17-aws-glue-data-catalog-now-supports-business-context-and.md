AWS Glue Data Catalog preview adds business context and semantic search, allowing enrichment with glossary terms and custom metadata fields so users can discover data by semantic meaning alongside technical metadata. MCP-compatible agents access trusted definitions via the aws-data-analytics plugin from Agent Toolkit for AWS.
