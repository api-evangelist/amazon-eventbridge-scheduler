AWS Secrets Manager offers a secret safety skill via the aws-core plugin, enabling developers to use secrets within agentic workflows without ever exposing secret values to the underlying model or session logs. A two-layer approach steers agents away from requesting raw secrets and resolves references at execution time outside agent processes.
