AWS Security Agent adds Kiro and Claude Code support for IDE integration, simulated exploit validation in sandboxes, and integrations with GitLab.com, GitLab Self Managed, GitHub Enterprise, Bitbucket, and Confluence. Simulated validations execute findings in an isolated environment and return evidence demonstrating how a vulnerability can be exploited.
