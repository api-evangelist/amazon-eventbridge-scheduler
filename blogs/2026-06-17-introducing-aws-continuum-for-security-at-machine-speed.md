AWS Continuum (gated preview) discovers, prioritizes, validates, and remediates security risks at machine speed. It ingests findings from existing tools, prioritizes using context graphs, validates exploitability in sandboxes, and delivers mitigations within guardrails, plus generates STRIDE-format threat models from design documents or source code.
