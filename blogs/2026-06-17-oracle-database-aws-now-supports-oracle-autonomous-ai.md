Oracle Database@AWS now supports Oracle Autonomous AI Database Serverless (ADB-S), a fully managed Oracle database service on Exadata infrastructure that automatically handles patching, tuning, and scaling. It supports four workload types, includes Autonomous Data Guard, automated S3 backups, and cross-Region disaster recovery, available in US East and US West.
