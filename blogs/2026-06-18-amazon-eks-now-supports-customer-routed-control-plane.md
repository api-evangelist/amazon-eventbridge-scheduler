Amazon EKS introduces customer-routed control plane egress, allowing organizations to route outbound Kubernetes API server traffic through their own Amazon VPC. This enables control over routing, security groups, and egress paths for admission webhooks, OIDC provider lookups, and aggregate API requests at no cost.
