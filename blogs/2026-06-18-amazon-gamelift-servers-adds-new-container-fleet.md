GameLift Servers now supports customizable Linux capabilities for containers and the ListContainersNetworkInfo() server SDK action for inter-container communication. Developers gain finer control beyond Docker's default capability set with NET_RAW and SYS_PTRACE support, and containers can discover co-located services.
