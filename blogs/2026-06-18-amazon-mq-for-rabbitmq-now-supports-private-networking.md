Amazon MQ for RabbitMQ enables private networking connectivity without exposing resources publicly, using VPC Lattice, AWS RAM, and PrivateLink to connect brokers to private identity providers (LDAP, OAuth 2.0) and self-hosted RabbitMQ brokers. Previously this required Network Load Balancer and NAT Gateway workarounds.
