title: "Amazon RDS for SQL Server increases the maximum size and provisioned performance of General Purpose (gp3) volumes"
url: "https://aws.amazon.com/about-aws/whats-new/2026/06/rds-sqlserver-increases-gp3-limits/"
date: "2026-06-18"
feed_url: "https://aws.amazon.com/about-aws/whats-new/recent/feed/"
---
RDS for SQL Server gp3 volumes now support up to 64 TiB in size (4X the previous 16 TiB limit), up to 80,000 IOPS (5X previous), and up to 2,000 MiB/s throughput (2X previous). With additional volume configuration, total capacity reaches 256 TiB per instance, with pricing unchanged.
