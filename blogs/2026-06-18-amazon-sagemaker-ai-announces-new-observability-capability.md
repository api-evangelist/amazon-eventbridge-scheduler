SageMaker AI offers new observability for inference endpoints, providing comprehensive visibility into token performance, GPU health, inference component placement, and autoscaling behavior. A pre-built CloudWatch dashboard displays token latency, GPU utilization, scaling events, and cold start metrics, with OpenTelemetry metrics published automatically.
