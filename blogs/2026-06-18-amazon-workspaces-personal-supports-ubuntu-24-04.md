AWS China (Ningxia) now offers Ubuntu 24.04 LTS bundles for WorkSpaces Personal, providing updated Linux packages, toolchains, and security improvements plus an extended support lifecycle. This offers a migration path for customers running older Amazon Linux 2 WorkSpaces.
