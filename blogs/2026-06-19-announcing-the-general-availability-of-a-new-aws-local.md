AWS launched a new Local Zone in Hanoi, Vietnam, extending core infrastructure to the metropolitan area with support for Amazon S3 and EBS Local Snapshots for data residency compliance. It offers EC2 instances (C7i, M7i, R7i), S3 One Zone-Infrequent Access, EBS volume types, ECS, EKS, VPC, Direct Connect, and Application Load Balancer, enabled via AWS Global View or the ModifyAvailabilityZoneGroup API.
